# Chile Travler (chiletravler.de)

Category: mobility-travel

## Concept
A travel inspiration guide to Chile for German-speaking travellers: regions from the Atacama desert to Patagonia and Easter Island, best times to travel, a sample 3-week route, and an interactive SVG map of Chile where clicking a region shows its highlights.

## Look
Warm and adventurous: terracotta, desert sand and Andes blue, a characterful serif for headings, generous whitespace; illustrations made with CSS/SVG (no stock photos).

## File Structure
- `index.html`: Main landing page featuring regions, an interactive map, travel times, and a route.
- `impressum.html`: Imprint page.
- `datenschutz.html`: Privacy policy page.
- `404.html`: Custom error page.
- `styles.css`: Styling including layout, typography, dark mode, and interactive map styles.
- `script.js`: Vanilla JavaScript for the interactive SVG region map.
- `favicon.svg`: Inline SVG favicon.
- `robots.txt` & `sitemap.xml`: Basic SEO files.
- `CNAME`: Configuration for GitHub Pages domain.
